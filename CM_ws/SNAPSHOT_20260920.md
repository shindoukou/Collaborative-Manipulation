## Validation and portability

The transfer was checked against SHA-256 hashes for 929 source/reference entries. Linux executable modes and the catkin top-level CMake symlink are retained in Git. The publication copy adds this note and ignore rules; it does not change algorithm code or weights.

Some scripts, selectors, and configuration files retain the original absolute Linux workspace paths and external ROS dependencies. A checkout at a different location needs path/dependency review. This commit does not claim a clean-machine build, a new Gazebo test, physical-robot validation, or full reproducibility of all historical experiments.

No controller was started for this commit. Before using physical-robot entry points, verify runtime mode, addresses, joint/controller interfaces, force calibration, reference selection, and timing against the actual installation.

The original remote `CM_ws` files and `TCST_ws` were not modified by this publication step.
